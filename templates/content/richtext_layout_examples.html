{% blocktrans %}Notice for authors{% endblocktrans %}

{% blocktrans %} In TinyMCE, you can work freely with HTML and use the approved TailwindCSS and DaisyUI utilities. Here is an overview of the most useful building blocks for layouts in guides and rich text content: {% endblocktrans %}

{# Layout #}

{% trans "Layout" %}

  • flex, inline-flex, grid, md:flex, md:grid
  • md:grid-cols-2, md:grid-cols-3, md:grid-cols-4
  • items-start, items-center, justify-between, justify-center
  • gap-4, gap-6, gap-8, my-6, space-y-3
  • w-1/2, w-1/3, w-2/3, max-w-lg, mx-auto
  • max-h-32, max-h-40, object-contain {% blocktrans %}(for images){% endblocktrans %}
{# Typography & Lists #}

{% trans "Typography & lists" %}

  • text-sm, text-base, text-lg, text-xl, text-2xl
  • font-medium, font-semibold, font-bold
  • leading-tight, leading-normal, leading-relaxed
  • text-left, text-center, text-right
  • list-disc, list-decimal, space-y-1 {% blocktrans %}(for list items){% endblocktrans %}
  • marker:text-primary, marker:text-accent {% blocktrans %}(for colored bullets){% endblocktrans %}
{# Components & Visual style #}

{% blocktrans %}DaisyUI components & visual style{% endblocktrans %}

  • alert, card, badge, btn {% blocktrans %}(for small CTAs only){% endblocktrans %}
  • rounded-md, rounded-lg, rounded-xl
  • border, border-base-200, border-base-300
  • bg-base-100, bg-base-200, bg-primary, bg-info, bg-warning
  • text-base-content, text-base-content/80, text-primary, text-accent
  • shadow, shadow-md, shadow-lg
