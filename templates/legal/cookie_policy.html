{% trans "What are cookies?" %}

{% blocktrans %} Cookies are small text files stored on your device when you visit a website. They provide technical functionality or convenience features (e.g., language or theme selection) and can also be used for statistical analysis. {% endblocktrans %}

{% trans "Cookies we use" %}

{% trans "This website uses the following types of cookies:" %}

1. {% trans "Technically necessary cookies" %}

{% blocktrans %} These cookies are required for the secure operation of the website and basic functions such as login, form security, language selection and navigation. They cannot be disabled in our systems. {% endblocktrans %}

  • csrftoken — {% trans "security cookie for form submissions (protection against Cross-Site-Request-Forgery attacks)" %}
  • sessionid — {% trans "stores an anonymous session ID to keep you logged in and process requests across pages" %}
  • django_language — {% trans "remembers your selected language (e.g. German or English) so that pages are displayed in the correct language" %}
  • htmx-current-path-for-history — {% trans "stores the current path to keep browser navigation and history working when using HTMX" %}
  • klaro — {% trans "stores your consent state for cookie categories and proves that consent has been obtained" %}

2. {% trans "Preference cookies" %}

{% blocktrans %} Preference cookies allow the website to remember information that changes the way the website behaves or looks, for example your selected light/dark theme. {% endblocktrans %}

  • preferred_theme — {% trans "remembers your selected theme (light/dark) for future visits" %}

3. {% trans "Statistics cookies (Google Analytics 4)" %}

{% blocktrans %} We use Google Analytics 4 to analyze how our website is used and to improve our content. Google Analytics 4 is deployed via Google Tag Manager. Statistics cookies are only activated after you have given explicit consent in the “Statistics” category in the Klaro dialog. Before consent is granted, Google Consent Mode v2 ensures that no Analytics cookies are stored and only anonymized, non-identifying signals may be transmitted. {% endblocktrans %}

  • _ga — {% trans "used to distinguish users and generate anonymous statistics (typically expires after 2 years)" %}
  • _ga_* — {% trans "used to maintain session state for Google Analytics 4 (typically expires after 1 year)" %}

{% trans "Cookie control" %}

{% blocktrans %} You can change or withdraw your consent at any time using the Klaro consent dialog available on this website (via the Klaro Cookie-Settings link at the bottom of the page). In addition, cookies can be blocked or deleted using your browser settings. {% endblocktrans %}

{% blocktrans %} Klaro also controls the execution of tracking technologies managed via Google Tag Manager based on your selected consent categories. This means that non-essential cookies and tags (such as Google Analytics) are only activated after you have given your consent. {% endblocktrans %}
